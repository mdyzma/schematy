# Memory Management

This folder contains documentation and strategies for managing AI agent memory and context across different platforms.

## Contents

- **[MEMORY_MANAGEMENT.md](./MEMORY_MANAGEMENT.md)**: A unified guide for cross-platform context synchronization. It covers:
    - Context Tiers (Static, Project-Specific, Dynamic).
    - The Unified Symlink Strategy for a single source of truth.
    - Implementation steps for Gemini CLI, OpenCode, Codex, and Claude Code.
    - Use cases for consistent persona behavior across tools.

## Purpose

The goal of these documents is to ensure that your AI assistant maintains a consistent "mental model" of your project and your personal preferences, regardless of which CLI tool you are currently using.
