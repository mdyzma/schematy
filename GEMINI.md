# GEMINI Context: Knowledge Library

## Project Overview
This directory, `knowledge-lib`, serves as a centralized knowledge base and reference repository for various AI agent frameworks and ecosystems. It focuses on documentation links and conceptual mappings between different platforms.

### Main Platforms Covered:
- **Gemini CLI:** Documentation, sub-agents, and skills.
- **OpenCode:** Rules, agents, and skills.
- **Codex (OpenAI):** Rules, guides, and open-source ecosystem.
- **Claude (Anthropic):** Permissions, agent teams, and memory management.

## Key Files
- **`basics.md`**: The primary reference file. It contains curated links to the official documentation of the supported platforms, categorized into:
    - **Rules & Permissions**: Guidelines for using the tools.
    - **Agents/Sub-agents**: Architectural information about AI agent implementation.
    - **Skills/Extensions**: How to extend the capabilities of the agents.
    - **Memory Management**: How different platforms handle context and persistence.
    - **Ecosystem**: Community resources, plugins, and extensions.

## Usage
The contents of this directory are intended to be used as a **quick-reference guide** for:
1.  **Cross-Platform Mapping**: Understanding how concepts (like "skills" or "memory") translate between Gemini, Claude, Codex, and OpenCode.
2.  **Fast Documentation Access**: Quickly retrieving the correct URL for specific platform features.
3.  **Contextual Awareness**: Providing Gemini CLI with the necessary background on related AI technologies during development or research tasks.

## Maintenance
- When adding new platforms or documentation updates, ensure the links are added to the appropriate category in `basics.md`.
- Keep the comparisons concise and focused on official documentation sources.
